VERSION 16 — WEEKLY NOTES WITH HARD-RULE PROTECTION

Run:
    pip install -r requirements.txt
    streamlit run app.py

Look for:
    Version 16 — weekly notes with hard-rule protection

New section under Weekly scheduling:
    Weekly notes / special requests

Example:
    Keep Conor as close to Kilburn as possible for Thursday

Rule hierarchy:
    1. Build normal valid schedule.
    2. Try the note separately.
    3. Commit it ONLY if the requested area/day can be achieved while all
       existing hard rules remain valid.
    4. Otherwise reject it and keep the baseline schedule.

Hard rules notes cannot override:
    - drawing/site eligibility
    - surveyor availability
    - no duplicate assignments
    - buffers / predicted durations
    - hard latest return
    - Google routes only the ONE selected week

Supported notes in v16:
    named surveyor + location preference + specific day/date

Rejected/accepted notes are visible in the app and exported to Weekly Notes.
