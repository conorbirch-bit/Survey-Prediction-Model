VERSION 13 — SALESFORCE MASTER + TEAM SCHEDULER

Run:
    pip install -r requirements.txt
    streamlit run app.py

Look for:
    Version 13 — Salesforce master import + team scheduling

This version accepts the Salesforce report export directly.

Automatic rules:
    Plan Drafting + Work Request = Needs Drawing
    Geospatial Asset Mapping = Ready

The importer also:
    - finds the real Salesforce header row
    - fills grouped Work Type / Status labels down
    - extracts postcodes from Building Name
    - ignores report footer rows

Team output now includes:
    Drawing Priority

Drawing Priority is a numbered queue for all Needs Drawing sites. Clusters
needed for the target survey week are placed first; the rest are ordered using
cheap portfolio signals without Google routing.
