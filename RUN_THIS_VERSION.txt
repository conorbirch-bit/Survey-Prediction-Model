RUN THIS AS A FRESH PROJECT

1. Extract this ZIP into a NEW folder.
2. Stop the old Streamlit app with Ctrl+C.
3. Open PowerShell in the new folder.
4. Run:

    pip install -r requirements.txt
    streamlit run app.py
