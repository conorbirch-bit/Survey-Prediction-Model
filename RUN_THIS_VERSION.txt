VERSION 8 — GOOGLE API KEY VIA STREAMLIT SECRETS

Run:
    pip install -r requirements.txt
    streamlit run app.py

For Streamlit Community Cloud:
1. Open the app.
2. Open app Settings.
3. Open Secrets.
4. Add:

    GOOGLE_MAPS_API_KEY = "YOUR_REAL_GOOGLE_API_KEY"

5. Save.

For local development:
1. Create .streamlit/secrets.toml
2. Add the same line above.
3. Restart Streamlit.

The real secrets.toml file is ignored by Git and should never be uploaded.
