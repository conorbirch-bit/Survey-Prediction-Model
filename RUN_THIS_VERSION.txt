VERSION 20.12.5 — STANDALONE CANNOT-COMPLETES ACCESS REPORT

Apply these changed/new files on top of version 20.12, then restart Streamlit.
Run: python -m streamlit run app.py
All scheduling and access classification rules remain unchanged.

Upload the two-tab Cannot Complete workbook. Click Generate cannot-completes
report to download the report without running a schedule. It is also generated
automatically alongside a successful team schedule when this workbook is supplied.

The separate workbook contains Summary, Client Access Required and All Cannot
Completes. The client tab includes original surveyor descriptions, date-only
visit columns and blank response/contact/access-date fields with a status dropdown.
Completed Work Orders are excluded from client help. Booking-week exclusions
never hide client-help cases; booked retries remain visible in the full register.

The register includes completed Work Orders found only in appointment mapping;
missing names, references and failure counts remain blank and are labelled.
It reflects the current upload, not historical rows absent from both source tabs.
Each fresh export starts with blank client response fields; retain client replies
separately. No new runtime dependencies or API calls are needed for Excel export.
Standalone classification can use the existing AI triage for unclear reasons.

Only app.py, retry_planner.py, this file, new access_report.py and the new report
tests are included. Keep all other version 20.12 files, training data and secrets.
